# Snake Game

A simple browser-based Snake game built with HTML, CSS, and JavaScript.

## Controls

- Use the arrow keys to move.
- Swipe on the game board on touch devices.
- Use the on-screen buttons on smaller screens.

## How it works

Eat the red fruit to earn points and grow. Every three points, the game speeds up and adds an obstacle. Avoid walls, obstacles, and the snake's tail.
